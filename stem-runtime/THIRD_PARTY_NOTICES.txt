Model weights
=============

The htdemucs, htdemucs_ft, hdemucs_mmi, mdx, mdx_extra, mdx_q, and
mdx_extra_q checkpoints are not included in Amethyst or its installer. Selected
weights are downloaded directly from Meta's public model host only after user
confirmation. The Demucs repository does not state a separate license for the
pretrained weights, and the upstream licensing question remains unresolved:
https://github.com/facebookresearch/demucs/issues/327

The four-stem BS-RoFormer checkpoint
model_bs_roformer_ep_17_sdr_9.6568.ckpt is likewise not bundled. It is
downloaded from the publisher's v1.0.12 GitHub release only after user
confirmation. The repository is MIT licensed, but does not state a separate
license for the released checkpoint; the upstream question is tracked here:
https://github.com/ZFTurbo/Music-Source-Separation-Training/issues/249

Portable CPython
================

The desktop stem runtime includes a stripped, relocatable CPython distribution
produced by python-build-standalone. CPython is distributed under the Python
Software Foundation License Version 2. The complete license is retained in the
bundled runtime.

Sources: https://github.com/astral-sh/python-build-standalone
         https://www.python.org/

PyTorch and TorchAudio
======================

The desktop stem runtime includes PyTorch and TorchAudio under their BSD-style
licenses. Their package metadata and license files are retained in the bundled
runtime. NVIDIA CUDA binaries are not included in the Amethyst installer; on
supported systems they are downloaded only after explicit user confirmation.

Sources: https://github.com/pytorch/pytorch
         https://github.com/pytorch/audio
